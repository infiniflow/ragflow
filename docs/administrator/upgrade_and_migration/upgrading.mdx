# Upgrade to Nightly or a Release
import Tabs from '@theme/Tabs';
import TabItem from '@theme/TabItem';

Upgrade RAGFlow to `nightly` or the latest, published release.

:::info NOTE
Upgrading RAGFlow in itself will *not* remove your uploaded or historical data. However, `docker compose --env-file docker/.env -f docker/docker-compose.yml down -v` removes Docker container volumes and causes data loss.
:::

## Upgrade RAGFlow to `nightly`, the Most Recent, Tested Docker Image

`nightly` refers to the RAGFlow Docker image without embedding models.

To upgrade RAGFlow, you must upgrade **both** your code **and** your Docker image:

1. Stop the server

   ```bash
   docker compose --env-file docker/.env -f docker/docker-compose.yml down
   ```

2. Update the local code

   ```bash
   git pull
   ```

3. Update **docker/.env**:

   ```bash
   RAGFLOW_IMAGE=infiniflow/ragflow:nightly
   ```

4. Update RAGFlow image and restart RAGFlow:

   ```bash
   docker compose --env-file docker/.env -f docker/docker-compose.yml pull
   docker compose --env-file docker/.env -f docker/docker-compose.yml up -d
   ```

## Upgrade RAGFlow to Given Release

To upgrade RAGFlow, you must upgrade **both** your code **and** your Docker image:

1. Stop the server

   ```bash
   docker compose --env-file docker/.env -f docker/docker-compose.yml down
   ```

2. Update the local code

   ```bash
   git pull
   ```

3. Switch to the latest, officially published release, e.g., `v1.0.0`:

   ```bash
   git checkout -f v1.0.0
   ```

4. Update **docker/.env**:

   ```bash
   RAGFLOW_IMAGE=infiniflow/ragflow:v1.0.0
   ```

5. Update the RAGFlow image and restart RAGFlow:

   ```bash
   docker compose --env-file docker/.env -f docker/docker-compose.yml pull
   docker compose --env-file docker/.env -f docker/docker-compose.yml up -d
   ```

## Frequently Asked Questions

### Do I Need to Back Up My Datasets Before Upgrading RAGFlow?

Yes. Before upgrading, stop all data-writing processes, create a complete backup of your configuration and persistent data from the same stopped deployment, and verify that it can be restored. Start with the [Migration Guide](./start_here.md), then follow [Backup and Restore (v0.x)](./backup_and_restore_v0.md) or [Backup and Restore (v1.x)](./backup_and_restore_v1.md) for your current version. Keep the verified backup until the upgraded deployment passes verification.

Upgrading is intended to preserve your uploaded data and dataset settings, but a failed migration may require restoring the complete pre-upgrade backup. The command `docker compose --env-file docker/.env -f docker/docker-compose.yml down -v` removes Docker container volumes and causes data loss.

### Upgrade RAGFlow in an Offline Environment (Without Internet Access)

1. From an environment with Internet access, pull the required Docker image.
2. Save the Docker image to a **.tar** file.
   ```bash
   docker save -o ragflow.v1.0.0.tar infiniflow/ragflow:v1.0.0
   ```
3. Copy the **.tar** file to the target server.
4. Load the **.tar** file into Docker:
   ```bash
   docker load -i ragflow.v1.0.0.tar
   ```
