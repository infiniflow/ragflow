# Introduction

RAGFlow is an open-source platform for building knowledge-grounded AI applications. Built on deep document understanding, it helps users transform complex, heterogeneous data into searchable, citable, and LLM-ready knowledge. RAGFlow provides an end-to-end workflow covering document ingestion, parsing, chunking, embedding, indexing, retrieval, and grounded answer generation, helping reduce hallucinations and improve traceability.

RAGFlow is designed for real-world unstructured and semi-structured data. It supports a wide range of document formats, including PDFs, Word documents, PowerPoint presentations, Excel spreadsheets, images, scanned documents, manuals, academic papers, tables, and Q&A files. With layout-aware parsing and multiple built-in chunking methods, RAGFlow preserves document structure, heading hierarchies, tables, and semantic context as much as possible. Users can also create custom ingestion pipelines to define how documents are parsed, processed, chunked, and transformed, producing high-quality knowledge for downstream retrieval and generation.

Beyond conventional RAG, RAGFlow provides advanced retrieval capabilities such as vector search, full-text search, hybrid search, cross-dataset retrieval, reranking, metadata filtering, automatic keyword and question generation, tag sets, and retrieval testing. These capabilities give users greater control over retrieval quality and help ensure that generated answers are grounded in relevant evidence.

RAGFlow also supports Knowledge Compilation, which transforms source documents and datasets into structured knowledge artifacts such as Wiki, Graph, Tree, PageIndex, Timeline, Mind Map, and Skills. Users can select a built-in compilation template or customize the compilation process to meet specific knowledge organization and application requirements. These artifacts make knowledge easier to explore, organize, retrieve, and reuse in downstream AI applications.

RAGFlow provides Search, Chat, and Agent capabilities for building knowledge-grounded AI applications. Search enables users to retrieve relevant content directly from connected knowledge bases. Chat combines knowledge retrieval with large language models to provide citable, knowledge-grounded conversations and support Agentic Retrieval. Depending on the selected Thinking mode, the system can analyze and rewrite questions, perform multi-step retrieval, evaluate available evidence, and refine its search before generating an answer. Agent enables users to build more complex AI applications by combining knowledge bases, models, memory, tools, and external services through a visual workflow editor.

The Agent framework provides a visual workflow editor for combining knowledge bases, models, memory, tools, and external services. Retrieval can be configured as part of a predefined workflow or exposed as a tool that an Agent can invoke when needed, enabling multi-step and tool-augmented applications.

Whether you are building a knowledge base, AI-powered search, a chat assistant, a research workflow, or a complex Agent application, RAGFlow provides an open-source and extensible foundation for connecting documents, data, retrieval, models, and tools into reliable, knowledge-grounded AI applications
