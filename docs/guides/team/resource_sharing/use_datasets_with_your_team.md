# Use Datasets with Your Team

Share a Dataset to allow team members to manage and use the same documents.

Joined members can find the shared Dataset in their **Dataset** list. If it does not appear, see [Why Can't an Invited User See Shared Resources?](../team_management/join_and_leave_teams.md#why-cant-an-invited-user-see-shared-resources).

When the owner changes the scope back to **Only me**, other team members lose access.

Members can view content, upload, parse, edit, or delete files, and update Dataset configuration. These changes affect everyone using the Dataset. Only the workspace owner can change its sharing scope or delete the Dataset itself.

See [Dataset configuration: Sharing Scope](../../dataset/configuration.md#sharing-scope) for the configuration steps.

## Parse Files as a Team Member

For parsing steps, see [Start Parsing](../../dataset/files_dataset_document_management.md#start-parsing).

Parsing uses the Dataset or pipeline's configured models from the Dataset owner's workspace, even when a member starts it. Members do not need to configure these models in their own accounts. If a model is unavailable, contact the owner to verify its configuration.

## Use a Shared Dataset in Chat

A shared Dataset does not automatically share a Chat that uses it. A member can create their own Chat and select the shared Dataset; that Chat uses its own configured chat model. See [Chat configuration: Datasets](../../chat/chat_configuration.md#datasets) to select it.
