# Use Memories with Your Team

Share a Memory to allow team members to use and manage its configuration and messages.

Joined members can find the shared memory in their **Memory** list and use it in workflows. They can view messages, edit memory configuration, enable or disable messages, and use **Forget**.

See [Memory configuration: Sharing Scope](../../memory/configure_memory.md#sharing-scope) for the configuration steps.

## Forget Messages or Delete a Memory

Use **Forget** to stop a message from appearing in retrieval results without immediately deleting its record.

Members can also delete the shared Memory. Once deleted, it is no longer available to any team member. Only the owner can change its sharing scope.

## Models Used by Shared Memories

Memory extraction and retrieval use the LLM and embedding model configured in the Memory owner's workspace, rather than members' default models. See [Configure Memory](../../memory/configure_memory.md) for model settings.
