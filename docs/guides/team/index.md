# Team Overview

Each account has its own workspace. Workspace owners can invite members, and account holders can join other teams to access shared resources.

Use the following links to access common tasks:

| Task | Guide |
| --- | --- |
| Invite team members | [Invite Members](team_management/manage_team_members.md#invite-members) |
| Accept a team invitation | [Accept or Decline an Invitation](team_management/join_and_leave_teams.md#accept-or-decline-an-invitation) |
| Configure resource sharing | [Resource Sharing and Permissions](resource_sharing/resource_sharing_and_permissions.md) |
| Review member permissions | [Team Member Permissions](resource_sharing/resource_sharing_and_permissions.md#member-permissions) |
| Review shared resource access conditions | [Resource Sharing and Permissions](resource_sharing/resource_sharing_and_permissions.md#access-rules) |

Joining a team gives you access only to resources the owner has shared with **Team**; private resources remain unavailable.
