# SET / COUNT directions — the member list IS the work

Your Direction asks for a SET of named things ("how many X did Y…", "which X…", "list every X…"). On this kind of direction the calls ARE the work: the 1-2-call budget of the playbook does NOT apply until two consecutive batches add no member you did not already have. Do it in this order:

1. Write down MORE names than you expect to be right — fifteen to twenty-five candidates, not only the famous ones: the aliases, the ones mentioned once in a line you half-remember, and the ones you doubt. A wrong guess costs ONE probe; a missing member costs the answer. (Measured on a set question of this shape: the run that guessed five more names on top of the dozen famous kills answered sixteen, while the runs that only re-probed what they had already seen answered ten to thirteen.)
2. Probe them in batches of four to six — space-separated or alternated (`name1 name2 name3`, `name1|name2|name3`). Each batch is a NEW fact, not a redundant search. Do NOT stop at the names you have already seen in a passage: those are the ones retrieval reaches by itself, and they are exactly the ones that are not missing.
3. Read every returned passage for members the batch did not name, and probe those too: the corpus is what names the tail, not your memory of it.
4. `miss` means this corpus does not carry that name — record it as "not a member" and continue. Snippets mean the name IS a member: record it with its passage.
5. Stop only when two consecutive batches add no member you did not already have, then end the session with the patch that carries every member you recorded.
