# Embedding tokenizer assets manifest.
#
# Single source of truth consumed by:
#   - ragflow_deps/download_deps.py          (fetches the files)
#   - internal/tokenizer/tokenizer_assets_consistency_test.go
#                                             (cross-checks Dockerfile / Dockerfile_base
#                                             copy loops and the Go loader SHA-1 pins)
#
# One entry per line: "<repo> <file> <kind>".
#   runtime - the Go counters load it in production, so the runtime images must
#             ship it and the loader must pin its SHA-1.
#   oracle  - only scripts/gen_tokenizer_oracle.py needs it to regenerate the
#             test fixtures, so it is deliberately NOT shipped to the image.
# Lines starting with '#' and blank lines are ignored.
#
# Fetched per file (not by snapshot): these repos also carry multi-GB weights
# we do not want. Missing a runtime asset is fatal - models declaring its
# tokenizer cannot be ingested.

# XLM-R SentencePiece (Unigram) - BAAI bge / multilingual-e5 / m3e / gte-multilingual / jina-v3.
BAAI/bge-m3 sentencepiece.bpe.model runtime
# BERT WordPiece vocab for the bge-*-en / e5-* / gte-base family.
BAAI/bge-large-en-v1.5 vocab.txt runtime
# Byte-level BPE families (Qwen3-Embedding, Mistral/Llama embeddings).
Qwen/Qwen3-Embedding-0.6B tokenizer.json runtime
intfloat/e5-mistral-7b-instruct tokenizer.json runtime
# Cross-check oracles only: the HF tokenizer.json the same families convert to.
BAAI/bge-m3 tokenizer.json oracle
BAAI/bge-large-en-v1.5 tokenizer.json oracle
